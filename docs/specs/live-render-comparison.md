# 实时渲染对比工具：产品约定

日期：2026-10-23。状态：用户已完成 grilling 并确认产品范围；尚未实现。技术决策由对应 Wayfinder 地图管理。

- 决策入口：[Wayfinder：本地实时渲染对比工具实施前决策地图](https://github.com/shuizhongyueming/canvas2d-webgl/issues/61)。

## 目标与边界

在当前仓库启动本地网页，让人工观察同一用例的原生渲染与兼容渲染，并检查自动差异量测是否符合肉眼观察。工具服务于反馈和后续量测规则调整，不签署正式验收，不修改既有验收门槛。

网页始终实时执行当前代码，不复用上次画面或执行结果，不保存历史结果和人工结论。无需登录、部署、多人协作或模型调用。

## 用例范围

- 候选来自现有 render 和 combined 用例；当前目录共 161 个候选，不承诺全部进入网页。
- 增加明确的展示资格标记和重点观察说明。只有两侧主画布具有直接对比意义的用例才进入列表。
- 排除只显示空白、标记，或主要依靠辅助画布/内部断言验证行为的用例。不能把这些结果标成原生/兼容视觉对照。
- 排除纯 semantic 用例、设施故障注入及真实游戏七场景。
- 不删除未入选的测试，也不削弱自动测试。当前 CI 没有运行完整浏览器矩阵；将完整矩阵加入 CI 不属于本工具范围。

## 页面交互

| 操作 | 约定 |
| --- | --- |
| 选择用例 | 下拉框、始终可见的上一项/下一项按钮、↑/↓ 快捷键 |
| 首尾行为 | 到达首尾停止，不循环 |
| 显示模式 | 左右分屏与重叠，两种模式均有按钮，V 键切换 |
| 左右分屏 | 原生、兼容分别完整显示，保持相同显示比例 |
| 重叠 | 两张独立画布同位置显示；原生在下、兼容在上；上层默认 50% 透明度，可调至 0% 或 100% |
| 显示比例 | 适应窗口与 1:1；放不下时允许滚动 |
| 背景 | 棋盘格、白色、黑色可切换；仅影响观察 |
| 重新运行 | 提供按钮，重新执行当前用例 |
| 复制 ID | 单独复制当前用例的唯一 ID |
| 复制反馈上下文 | 只含用例 ID、浏览器信息、本次差异数据；不含代码版本、工作区状态 |
| 键盘冲突 | 下拉框、滑杆或输入控件操作期间，不触发页面级切换快捷键 |

页面内切换用例保留分屏/重叠模式、透明度、背景及显示比例。刷新恢复默认，不做持久化。已明确的默认值为重叠透明度 50%；其余初始显示值由实现合理选择。

## 实时执行与销毁

1. 两侧使用相同输入和随机种子，保持独立执行环境。
2. 完成可控的资源准备后，页面向两侧共同发出开始信号。不保证逐帧同步，不修改原有用例的时间推进语义。
3. 人工可观察运行全过程；机器只在两侧完成后比较最终画面。
4. 执行中展示状态，不提前显示最终差异结果。
5. 切换或重新运行时，销毁旧执行环境并立即清除旧画面、指标和错误。旧异步任务不得影响新用例。
6. 执行失败显示具体错误，不保留旧结果冒充当前结果，不把失败解释成一致。
7. 不做暂停、慢放、逐步执行，也不将这些功能列为后续计划。

## 自动差异量测

- 分别取得两张画布各自最终的原始像素；不比较重叠合成后的图像或页面缩放截图。
- 展示差异像素占比、最大通道差、差异区域及可切换的差异图。
- 重叠透明度、显示比例和背景不改变量测输入或计算结果。
- 不提供单一相似度分数，不把差异像素占比改名为相似度，不自动判通过/拒绝。
- 不调用 AI 生成评审意见。自动量测与 AI 评审、正式一致性评审是不同概念。
- 具体像素规范化、透明像素处理、尺寸不一致及空输出的行为，在技术决策票中明确，不借此引入新容差。

## 人工反馈流程

选择用例 → 观察两种显示模式和运行过程 → 查看最终差异 → 复制 ID 或反馈上下文 → 向 AI agent 描述问题 → agent 调整实现或量测规则 → 人工重新运行验证。

本工具不保存人工意见，也不生成 reviews.json，不替人工或 AI 签署正式评审。正式矩阵验收与七场景验收仍由各自跟进票负责。

## 实现前事实

截至当前检查版本 8935998：现有目录有 252 semantic、107 render、54 combined。execute 会创建 target、替换 Math.random 并保留画布等待截图；清理依赖 driver 关闭整个浏览器 context，不能直接在一个文档重复调用来满足本工具。用例协议没有 teardown 或 AbortSignal；Promise.race 超时也不终止底层任务。

现有 catalog、执行入口和差分函数可作为复用候选，但不以复用为由降低隔离与清理要求。最终执行承载方式、展示标记位置及量测协议由地图中的决策票确定。

## 交付核验场景

- 下拉、按钮和快捷键选择同一用例，结果一致；首尾不越界，控件键盘操作不被抢占。
- 快速连续切换、执行中切换、失败后切换均不出现旧画面或旧回调写入。
- 改变重叠透明度、背景或显示比例时，本次量测结果不变。
- 重跑不使用前一次图像或结果；非直观用例不入列表，但仍存在于原自动测试目录。
- 差异图和指标只定位差异，不显示自动验收通过。
